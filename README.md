## Portfolio Website

This project is a personal portfolio website created to showcase my journey as a junior developer, my skills, and my contact details. The site introduces who I am, highlights the technologies I have learned, and presents my projects and professional interests.

### Technologies Used
- HTML
- CSS
- JavaScript

### Site Link
https://emmanuel-kimutai-portfolio.netlify.app

### Description
The website is designed as a clean and simple portfolio page for Emmanuel Kimutai. It includes a short introduction, information about his background, a skills section, a projects section, and contact information so visitors can learn more about him and reach out easily.
